# Charlie's Neovim Configuration
This is my very own neovim configuration

## Set up
There are a couple of packages OS dependencies that you need to install to set up this configuration (some plugins depend on them)

    - brew install lazygit
    - brew install onefetch
    - brew install ripgrep
    - brew install fd
    - brew install tree-sitter tree-sitter-cli 

Run `:Lazy install` to install the plugins
